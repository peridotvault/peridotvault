## Tone and voice

### Words to use

Direct, specific, number-forward, factual. Prefer verbs over adjectives. Prefer nouns over metaphors. Say what an action does, not what it feels like.

### Words to avoid

Hype words (revolutionary, game-changing, unleash, supercharge), emojis, exclamation marks, overpromising. "Unlock" is banned.

### Voice example

> "Mint your game license on-chain. True ownership, no lock-in."

## Usage dos and don'ts

**Do:**

- Use the CSS variables (`bg-background`, `text-foreground`, `bg-primary`, `text-paragraph`) everywhere. Never hardcode hex.
- Keep the 4 px spacing grid (`gap-2`, `p-4`, `px-6`).
- Use `font-mono tabular-nums` for any number that updates in place (balances, prices, counters).
- Test every component in dark mode (only supported theme).

**Don't:**

- Hardcode colors (`#FF0000`, `rgb(...)`) in component files.
- Use `transition: all` — always specify `transition-colors`, `transition-transform`, etc.
- Override tokens per-component — if a color is wrong, fix it in `token/colors.css` once.
